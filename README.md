## 編譯方式

請先進入教學文件所在的資料夾：

```bash
cd git_tutorial
```

接著使用 XeLaTeX 編譯：

```bash
xelatex git_basic_tutorial.tex
xelatex git_basic_tutorial.tex
```

編譯兩次可以正確產生目錄。
